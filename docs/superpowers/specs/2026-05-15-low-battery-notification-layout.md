# 低电量通知设置区域 — 抽屉式折叠布局

## 背景

当前 6 个开关（手柄震动/灯带变色/手柄音频/托盘气泡/系统提示音/总开关）各占一行，共 12 行，空间浪费严重。需要压缩为紧凑的抽屉式布局。

## 设计决策

选择 **C2 精炼型**：总开关 + 可折叠抽屉 + 2 列子开关 + 关闭蒙版。

## 布局结构

```
低电量通知（节标题）
┌──────────────────────────────────┐
│ [总开关] ▼                      │  ← 总开关行（带折叠箭头）
├──────────────────────────────────┤
│ ┌──────────────────────────────┐ │
│ │ 手柄震动 [·]  灯带变色 [·]  │ │  ← 暗底卡片 · 2 列 grid
│ │ 手柄音频 [·]  托盘气泡 [·]  │ │
│ │       系统提示音 [·]         │ │  ← 奇数项跨列居中
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│ 电量阈值 / 重复提醒 / 提醒间隔   │
└──────────────────────────────────┘
```

## 三种状态

### 1. 展开 + 总开关开启
- 总开关切换按钮蓝色、on 态
- 箭头 ▼ 表示展开
- 子开关面板可见，各自独立操作

### 2. 折叠态
- 箭头 ▶ 表示收起
- 子开关面板隐藏（Collapsed）
- 下方其他配置（电量阈值等）自动上移

### 3. 关闭蒙版态（总开关 off）
- 子开关面板仍然可见但覆半透明灰色蒙版
- 所有子开关状态保留但视觉不可操作
- 蒙版居中显示 "提醒已全部禁用"
- 总开关 of 态（灰色）

## 交互规则

- **点击总开关行**：切换总开关 on/off
- **点击箭头 ▼/▶**：折叠/展开子面板
- **总开关 off 时**：子面板展示蒙版，所有子开关视觉禁用
- **总开关 on 时**：蒙版消失，子开关可正常操作

## 实现要点

### XAML 结构

```
低电量通知 节标题
├── 总开关行（Border 包裹）
│   ├── CheckBox（总开关，ToggleSwitch 样式）
│   ├── TextBlock（"总开关"）
│   └── TextBlock（▼/▶ 箭头）
├── 子开关面板（Border 暗底卡片，Visibility 绑定折叠状态）
│   ├── 关闭蒙版（Border 半透明遮罩，Visibility 绑定总开关!）
│   └── Grid 2列
│       ├── 手柄震动 CheckBox
│       ├── 灯带变色 CheckBox
│       ├── 手柄音频 CheckBox
│       ├── 托盘气泡 CheckBox
│       └── 系统提示音 CheckBox（Grid.ColumnSpan=2）
├── 电量阈值 Slider
├── 重复提醒 CheckBox
└── 提醒间隔 预设按钮
```

### 代码后置逻辑

- `ChkAlertEnabled` 切换 → 更新蒙版 Visibility
- 箭头点击 → 切换子面板 Visibility + 翻转箭头方向
- 子开关 CheckBox 加载/保存 → 复用现有 `HapticEnabled` 等属性

### AppSettings — 无变化

复用现有属性：`LowBatteryAlertEnabled`, `HapticEnabled`, `LightbarEnabled`, `ControllerSpeakerEnabled`, `BalloonTipEnabled`, `AlertSoundEnabled`
